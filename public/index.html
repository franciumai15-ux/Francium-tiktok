Search TikTok and get video details, creators, and captions as structured JSON.

This page prepares a command to run on your computer. Searches run through the command-line tool; this site does not run them.

02 /Run your command

node tiktok-search.mjs 'funny cats' --tab video
Open on TikTok ↗

Ready to copy. Run from the project folder.

First time here?

Install Node.js 20 or newer, then download the project and extract it. Open a terminal in that folder and run the command above.

The tool prints JSON to your terminal. Add > results.json to save the output to a file. For more options, run node tiktok-search.mjs --help.

TikTok may block automated requests or return empty results. See the troubleshooting guide for details.
